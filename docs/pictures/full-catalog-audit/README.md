# Revisión completa del catálogo

297 fotos recuperadas de los cuatro ZIP y verificadas por SHA-256.

477 fichas preparadas: 183 existentes y 294 nuevas verificadas visualmente. 105 observaciones necesitan datos del dueño; no son necesariamente 105 productos diferentes. Se resolvieron cuatro duplicados.

Las fotos originales completas se usan donde falta una imagen individual. Las etiquetas compartidas solo se aceptaron en grupos de variantes identificables de la misma presentación; no se extrapolaron precios entre tamaños.

CSV del catálogo: catalogo-publicado.csv. Pendientes: datos-por-confirmar.csv, con foto y motivo. decisions.json conserva cada decisión.

La función pública de pedidos usa el mismo catálogo y validación de precios que la API web. Sus archivos locales deben actualizarse y desplegarse cada vez que cambie el catálogo o el tarifario.
